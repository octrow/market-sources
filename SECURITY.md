# Security policy

**English** | [Русский](SECURITY.ru.md)

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/octrow/market-sources/security/advisories/new).
You should get a reply within a week.

## Supported versions

Only the latest release gets fixes.

## Scope

In scope: problems in this library's code, for example a proxy URL or credentials leaking into logs or
exceptions, unsafe handling of response data, or a dependency with a known vulnerability.

Out of scope: the marketplaces themselves (Kaspi.kz, OLX.kz, Ozon.kz). Report issues with their sites to them.
